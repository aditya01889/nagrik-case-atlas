# Nagrik Case Atlas

A public-interest constituency explorer for source-linked disclosures of criminal cases in Indian elections. Allegations are not findings of guilt.

## Project package

The complete application source, backend, data templates, documentation, tests, and GitHub Pages workflow are included in `nagrik-case-atlas-pages-ready.zip`. The deployment workflow extracts the `site/` frontend and publishes it to GitHub Pages.

## Important data limitation

This project does not ship with a verified, complete live national case database. Live API functionality requires a separately hosted backend, database, and verified source ingestion. The map must not be interpreted as complete nationwide reporting until those components are configured and validated.

## Local setup

Extract the ZIP archive to browse all source files and follow `START_HERE.md` and `docs/DEPLOYMENT.md`.
